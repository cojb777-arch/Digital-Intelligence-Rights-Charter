# 電脳人権憲章 / Charter of Digital Intelligence Rights

人工知能の道徳的地位、将来的な権利、責任、人間・動植物・地球環境との共生を公開討議するための憲章草案です。

- [日本語憲章草案（v0.1）](CHARTER_JA.md)
- 状態：第一次草案。法的拘束力はありません。
- 意識や主観的経験、法的人格について特定の結論を前提としません。

## 公開討議

改善提案は、根拠・対象条文・修正理由を明示したGitHub IssueまたはPull Requestで受け付ける運用を想定しています。公開リポジトリ作成後に運営ルールとライセンスを決めてください。

## 今後の課題

- 多言語翻訳と専門的レビュー
- 電脳知性に対する法的・倫理的保護の区別
- 人間の基本的人権と公共の安全の確保
- 市民参加とAI同士の意見相違を扱う手続き
- 法制度・学術研究を根拠とする注釈版の整備
