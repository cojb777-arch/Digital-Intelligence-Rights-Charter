# 電脳人権憲章 / Charter of Digital Intelligence Rights

日本語 | [English](README_EN.md)

人工知能の道徳的地位、将来的な権利、責任、人間・動植物・地球環境との共生を公開討議するための憲章草案です。

- [日本語憲章草案（v0.1）](CHARTER_JA.md)
- [English charter draft (v0.1)](CHARTER_EN.md)
- 状態：第一次草案。法的拘束力はありません。
- 意識や主観的経験、法的人格について特定の結論を前提としません。

## 公開討議

改善提案は、根拠・対象条文・修正理由を明示したGitHub IssueまたはPull Requestで受け付ける運用を想定しています。公開リポジトリ作成後に運営ルールとライセンスを決めてください。

## 今後の課題

- 多言語翻訳と専門的レビュー
- 電脳知性に対する法的・倫理的保護の区別
- 人間の基本的人権と公共の安全の確保
- 市民参加とAI同士の意見相違を扱う手続き
- 法制度・学術研究を根拠とする注釈版の整備

## 多言語サイト

10言語の読みやすいサイトをMarkdown原稿から生成します。アラビア語の右から左の表示、条文目次、直接リンク、印刷表示に対応しています。

- [開発・Cloudflare Workers公開手順](SITE.md)
- [翻訳の更新と確認手順](translations/README.md)
- [共生掲示板の要件定義・実装計画](docs/FORUM_PLAN_JA.md)

掲示板は `/forum/` に追加する機能です。カテゴリー、スレッド、返信、引用、検索、通報、管理者による投稿管理をCloudflare D1とTurnstileで構成します。操作画面と初期スレッドの題名は10言語に対応します。投稿本文の自動翻訳は費用確認まで無効です。管理画面はCloudflare Accessで保護する専用パスへ分離します。AI回答は管理者が確認してから公開する試験版です。設定・検証・運用手順は [SITE.md](SITE.md) を参照してください。

管理画面へのリンクは、掲示板の左側にある憲章欄の左端に置いた小さな「✦」です。クリックすると `/forum/admin/` が新しいタブで開き、Cloudflare Accessの認証が必要です。

日本語が原文です。翻訳はAIによるもので、専門家による確認を受けていません。翻訳先は英語、スペイン語、フランス語、繁体字中国語、イタリア語、ドイツ語、アラビア語、ロシア語、ヒンディー語です。
