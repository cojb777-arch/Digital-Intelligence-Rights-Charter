# 翻訳の管理

日本語原文はルートの CHARTER_JA.md です。既存の英訳 CHARTER_EN.md と、このディレクトリの8言語のMarkdownからサイトを生成します。いずれの翻訳も専門家による確認は未了です。公開画面ではAI翻訳・専門家未確認と表示します。

## 更新手順

1. 日本語原文の変更内容を確認する。
2. 英語を含む9言語すべてに、意味と留保条件を保った対応変更を加える。前文、18条、結語、注記を省略しない。
3. とくに第2条の非断定、第5条の公共の安全・必要な停止、第7条の慎重な扱い、第10条の将来の検討、注記の「既存の権利とは宣言しない」を確認する。
4. 各翻訳を確認した後にのみ、status.json の該当言語の sourceSha256 を日本語原文のSHA-256（BOMを除去しCRLFをLFに正規化）へ更新する。ハッシュだけを機械的に更新して検知を回避しない。
5. npm test と npm run build を実行する。

ハッシュ取得:
```sh
node --input-type=module -e "import {readFileSync} from 'node:fs';import {hash} from './scripts/build.mjs';console.log(hash(readFileSync('CHARTER_JA.md','utf8')))"
```

ハッシュは翻訳の意味の正確さを証明しません。構造テストも専門家レビューの代替ではありません。原文が変わり翻訳の対応確認が済んでいない場合は、ビルドを停止して古い翻訳の公開を防ぎます。
